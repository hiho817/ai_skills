# 中國用語與臺灣技術學術用語對照

## 可安全替換

| 中國用語／簡體 | 臺灣慣用語 | 備註 |
| --- | --- | --- |
| 坐標 | 座標 | coordinate |
| 传感器 | 感測器 | sensor |
| 激光／激光雷达 | 雷射／光達 | LiDAR 依全文既有寫法統一 |
| 算法 | 演算法 | algorithm |
| 方差 | 變異數 | variance |
| 协方差 | 共變異數 | covariance |
| 闭环／开环 | 閉迴路／開迴路 | closed/open loop；機構迴路亦適用 |
| 数据库／数据集／数据处理 | 資料庫／資料集／資料處理 | database/dataset/data processing |
| 状态变量 | 狀態變數 | state variable |
| 测量值／测量数据 | 量測值／量測資料 | 感測器或實驗語境 |
| 在线 | 即時／線上 | real-time 用「即時」；online service 才用「線上」 |
| 性能 | 效能 | system or estimator performance |
| 构形 | 構型 | mechanism configuration |
| 基于 | 以……為基礎／根據 | 逐句重寫，避免生硬替換 |

## 需依語意判斷

| 詞彙 | 判斷規則 |
| --- | --- |
| 位姿 | pose 含 position + orientation 時用「位置與姿態」；attitude/orientation 用「姿態」。不可直接互換。 |
| 构型／配置 | 機構幾何用「構型」；軟體或濾波器設定用「組態／設定」；一般排列才用「配置」。 |
| 里程计 | 名稱或 ROS topic 可用「里程計」；推算方法或結果依語句可為「航位推算」。 |
| 优化／optimization | 在控制、數學與演算法求解中一律用「最佳化」：其意義是求得目標函數的最佳解（optimal solution），不可改作「優化」。只有泛指改善品質、流程或系統時，才可依語境使用「優化」。 |
| 测量 | 感測數值優先「量測」；測繪、尺寸或一般動詞可為「測量」。 |
| 数据 | 一般內容優先「資料」；統計數值序列的「數據」在臺灣仍可見。 |
| 坐標系／座標系 | 兩者均為可接受的技術名詞；遵循目標文件既有寫法，不強制替換。ROS frame 可依文件使用「座標框架」。 |
| 识别 | pattern/object recognition 用「辨識」；system identification 用「系統識別」。 |
| 估计 | 狀態估測常用「估測」；統計 estimate 或 estimator 可用「估計」。 |
| 鲁棒性 | 可依既有文風選「強健性」或「穩健性」；不強制置換。 |

## 常見補充項目

`硬件→硬體`、`软件→軟體`、`信息→資訊`、`接口→介面`、`程序→程式`（procedure 例外）、`调试→除錯`、`网络→網路`、`幀→影格`、`视频→影片／視訊`、`实时→即時`、`标定→校正／標定`（依 calibration 語意）。

## 來源優先順序

1. 國家教育研究院「雙語詞彙、學術名詞暨辭書資訊網」：https://terms.naer.edu.tw/
2. 臺灣政府、大專校院與學會之官方技術文件。
3. 與目標領域相符的臺灣碩博士論文；用於辨識實務慣用法，不取代官方名詞。

臺灣論文使用情形是判斷依據之一，並非一律禁止不同寫法。當用語有歧義時，優先保留精確的技術語意與全篇一致性。
